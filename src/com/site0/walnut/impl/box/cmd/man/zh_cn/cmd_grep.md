# 命令简介

`grep` 从管道或文件中筛选匹配的行

两种匹配方式：`-e` 正则（对去除首尾空白的行做查找）或子串包含。
默认读管道输入，`-f` 时从文件读取（支持多个候选对象，目录自动跳过）。

# 用法

```bash
grep [-e 正则] [-f 文件] [子串]
  -e    # 正则表达式（与子串二选一）
  -f    # 从文件读取内容（默认读管道）
```

# 示例

```bash
# 管道过滤：保留包含 error 的行
cat ~/log.txt | grep error

# 正则匹配
cat ~/log.txt | grep -e '^\d{4}-\d{2}'

# 从文件读取
grep -f ~/log.txt -e timeout
```
