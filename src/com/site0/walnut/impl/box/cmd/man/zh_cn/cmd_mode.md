# 命令简介

`mode` 权限码分析工具：显示或换算对象的权限码

输入可以是八进制数、十进制整数或 `rwx` 字符串；输出三种形式互相对照。
`-f` 文件模式下输入是对象路径，直接读取该对象的权限。

# 用法

```bash
mode [输入] [-octal] [-f] [-real]
  -octal    # 输入按八进制解析（如 777）
  -f        # 文件模式：输入是对象路径
  -real     # 文件模式下，获取原生权限码（默认取自定义权限码 pvg）
```

# 示例

```bash
# 八进制输入
mode 777 -octal

# 十进制整数输入
mode 488

# rwx 字符串输入
mode rwxr-x---

# 查看文件的权限
mode ~/abc.txt -f
```
