# 命令简介

`random` 输出随机数

三种模式：`-s` 生成 N 位数字串；给范围生成区间内整数；无参数生成
0.0~1.0 的随机浮点数。

# 用法

```bash
random [-n] [-s 位数] [最小值,最大值]
  -s    # 数字串模式：位数（默认 4），每位为 0-9
  -n    # 结尾输出换行
```

# 示例

```bash
# 0-6 之间的随机整数
random 6

# 18 至 100 内的随机整数
random 18,100

# 4 位随机数字串（如短信验证码）
random -s 4

# 0.0 至 1.0 的随机浮点数
random
```
