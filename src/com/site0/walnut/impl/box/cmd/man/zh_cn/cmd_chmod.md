# 命令简介

`chmod` 修改对象的权限模式（`mode`）

模式支持两种写法：八进制（如 `644`）或符号形式（`+rwx` / `-rwx` / `=rwx`）。
符号形式对属主/同组/其他三类权限同时生效，暂不支持按类细分。

# 用法

```bash
chmod [-Rv] 模式 路径...
  -R    # 递归处理目录下的所有子孙对象
  -v    # 每修改一个对象，输出其相对路径
```

# 示例

```bash
# 八进制方式设置权限
chmod 644 ~/readme.txt

# 给脚本加上执行位
chmod +x ~/bin/deploy

# 递归开放目录读权限，并显示改动
chmod -Rv +r ~/share
```
