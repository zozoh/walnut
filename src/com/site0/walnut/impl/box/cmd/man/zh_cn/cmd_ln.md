# 命令简介

`ln` 创建链接

默认创建硬链接（记录 `id:xxx`，源对象始终有效）；`-s` 创建软链接
（记录路径，源被删除后失效）。目标已存在时默认报错，`-f` 强制覆盖。

# 用法

```bash
ln [-sf] 源路径 目标路径
  -s    # 软链接（记录路径）；相对源记相对路径，绝对源（/ 或 ~ 开头）记绝对路径
  -f    # 目标已存在时先删除再创建
```

# 示例

```bash
# 创建软链接文件
ln -s ~/abc.txt ~/yyy.txt

# 创建软链接目录
ln -s ~/myfolder ~/newfolder

# 创建硬链接
ln ~/abc.txt ~/hard.txt
```
