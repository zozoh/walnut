# 命令简介

`hex` 以十六进制形式查看文件或管道内容

每行输出 `地址: 字节序列`，地址为 7 位十六进制。多个文件时输出 `FILE:` 头分隔。

# 用法

```bash
hex [-w 宽度] [-from 起点] [-to 终点] [文件...]
  -w      # 每行字节数（默认 16）
  -from   # 起始字节（向下对齐到行宽）
  -to     # 结束字节（0 表示到末尾）
```

# 示例

```bash
# 查看文件
hex ~/bin.dat

# 查看前 64 字节
hex -to 64 ~/bin.dat

# 从管道读入
cat ~/bin.dat | hex -w 8
```
