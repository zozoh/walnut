# 命令简介

`passwd` 修改系统用户的密码

修改他人密码需要 root/op 组成员；root/op 组成员之间不能互改。
`-old` 会先验证旧密码（从未设置过密码则不验）。

# 用法

```bash
passwd [新密码] [-old 旧密码] [-u 用户]
  -old    # 先验证旧密码
  -u      # 指定目标用户（登录名/手机号/邮箱/ID），缺省为当前用户
```

# 示例

```bash
# 修改自己的密码
passwd 123456

# 修改自己的密码，先验证旧密码
passwd 654321 -old 123456

# 管理员重置他人密码（系统自动生成新密码）
passwd -u xiaobai

# 管理员指定新密码
passwd 123456 -u xiaobai
```
