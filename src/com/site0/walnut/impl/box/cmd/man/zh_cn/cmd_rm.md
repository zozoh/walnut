# 命令简介

`rm` 删除对象

支持 `*` 通配符批量删除。默认跳过隐藏对象；删除目录需要 `-r` 递归。
删除走正常删除流程（触发钩子），不可恢复。

# 用法

```bash
rm [-rvIH] 对象...
  -r    # 递归删除目录及其子孙
  -v    # 输出每个被删对象的相对路径，结束时打印统计
  -I    # 配合 -v，输出带序号
  -H    # 包含隐藏对象（默认跳过）
```

# 示例

```bash
# 删除文件
rm ~/tmp.txt

# 递归删除目录
rm -r ~/tmp

# 批量删除
rm ~/log/*.txt

# 删除并显示过程
rm -rv ~/tmp
```
