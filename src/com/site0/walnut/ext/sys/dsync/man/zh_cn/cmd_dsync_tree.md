# 过滤器简介

`@tree` 构建或加载对象的索引树。

# 用法

```bash
dsync @tree [SHA1] [-f] [-I] [-H]
       # SHA1    # 指定包的指纹，根据配置信息以及指纹能确定唯一的包名；
                 # 不指定则操作 HEAD 索引树，否则从缓存目录加载对应的索引树
  -f       # 仅对 HEAD 有效：强制重新建立索引树；
           # 否则自动比对索引树文件与目标目录的同步时间，不同才重建
  -I       # 确保为所有的索引项目都加载了 WnObj 数据
  -H       # 仅加载现有的 HEAD 索引树
```

# 示例

```bash
# 根据域文件内容，生成索引树
dsync @tree @as
# ------------------------------------------------------------
# DSYNC PACKAGE: [dsync-6e3b41d6e5e1fb29caa3dc45a8abdac718d5d8ac.zip]
# ------------------------------------------------------------
# TREE[dsync-site]
# sync_time: 2021-03-30 23:51:15
# item_count: 2426
# ...
```
