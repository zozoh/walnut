# 命令简介

`i18n` 命令提供系统本地化字符串支持。

命令假设本地化字符串在系统中按下面的格式存放：

```bash
/etc/i18n
    zh-cn        # 每个文件就是一个多行属性
    en-us        # 一个语言一个文件
```

# 用法

```bash
i18n [lang] [-k 键] [-cqn] [-reload]
  lang     # 指定语言；不指定时使用 $LANG，默认 zh-cn
  -k       # 获取指定键的值；不给则输出整个语言的键值集合
  -reload  # 重新刷新缓存
  -c       # 输出集合时，JSON 紧凑显示
  -q       # 输出集合时，键名用双引号包裹
  -n       # 输出集合时，null 值的键不忽略
```

# 示例

```bash
# 输出整个语言的键值集合
i18n

# 输出某个键的值
i18n -k e.a.b

# 获取英文的某个键
i18n en-us -k e.a.b

# 刷新缓存
i18n -reload
```
