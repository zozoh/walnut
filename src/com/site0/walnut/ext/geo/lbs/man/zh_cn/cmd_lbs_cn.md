# 过滤器简介

`@cn` 获取中国全部省市区县直到街道的地址详情。

查询依赖`中华人民共和国行政区划代码`：

```bash
# 直辖市: 直辖市 > 01 > 区县 > 乡镇/街
#   北京 11 / 天津 12 / 上海 31 / 重庆 50，香港 81，澳门 82
# 普通地址: 省 > 市 > 区县 > 乡镇/街
# 地址对象形如
{
  "code": "110108017000",
  "name": "清河街道",
  "province": "11",
  "city": "01",
  "area": "08",
  "town": "017000"
}
```

# 用法

```bash
lbs @cn [地址编码] [-list] [-ajax] [-cqn] [-notown]
       # 地址编码    # 类似 110108 的编码；不给则取顶级省/直辖市列表
  -list      # 获取其下子地址编码列表
  -ajax      # 按 AJAX 格式输出，默认按 JSON 方式
  -cqn       # JSON 输出的格式化开关
  -notown    # 列表模式摘要输出时，为 notown 地址打上后缀标识
```

# 示例

```bash
# 获取中国顶级省/直辖市列表
lbs @cn -list -q
# [{"code":"110000","name":"北京市","province":"11",...}]

# 获取某地址下一级地址列表
lbs @cn 110000 -list -q

# 获取一个地址的详情
lbs @cn 110108003000 -q
# {"code":"110108003000","name":"羊坊店街道","provinceName":"北京",...,"areaName":"海淀区","town":"003000"}
```
