# 过滤器简介

`@re` 统一处理支付单平台的回调。

- 如果支付单填写了回调执行脚本，也会一并执行
- 如果支付单已经完成，不会重复执行，但输出同样的结果

命令输出与 `@send` 格式相同。

# 用法

```bash
pay @re [回调JSON] [-idkey 键] [-s]
  # 回调JSON    # 回调发送的请求；不给则从标准输入读取
  -idkey   # 请求参数中表示支付单 ID 的键名
  -s       # 输出成功字符串 success
```

# 示例

```bash
# 处理某支付单的回调
httpparam -in id:xxx | pay @re 45..e3 -s
```
