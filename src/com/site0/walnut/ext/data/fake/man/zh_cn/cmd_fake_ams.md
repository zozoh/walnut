# 过滤器简介

`@ams` 生成绝对毫秒数。

# 用法

```bash
fake [个数] @ams [开始时间] [随机区间] [-as 格式] [-i]
  # 个数        # 生成多少个，默认 1
  # 开始时间    # 日期时间或绝对毫秒数，默认 today
  # 随机区间    # 毫秒数表达式，表示一个随机区间，默认 5m
  -as         # 输出的类型："AMS" 输出绝对毫秒数（默认），其他值作为日期格式化
  -i          # 自动递增：同一个实例每次调用累加区间下标，生成连续的时间
```

# 示例

```bash
# 输出连续三个绝对毫秒数，并按指定格式输出
fake 3 @ams today 5m -as "yyyy-MM-dd'T'HH:mm:ss.SSS" -i
# 2021-05-16T00:01:00.729
# 2021-05-16T00:06:50.763
# 2021-05-16T00:11:40.054
```
