# 过滤器简介

`@hexs` 生成多段随机整数（16 进制），可用来生成 MAC 地址、颜色值等。

# 用法

```bash
fake [个数] @hexs 模板 [-upper]
  # 个数        # 生成多少个，默认 1
  # 模板        # 如 '2R0:#{0-FF}{0-FF}{0-FF}' 生成颜色
              #    '2R0:{0-FF}:{0-FF}:{0-FF}:{0-FF}:{0-FF}:{0-FF}' 生成 MAC 地址
  -upper      # 输出大写十六进制字符
```

# 示例

```bash
# 随机生成 3 个网卡地址
fake 3 @hexs -upper '2R0:{0-FF}:{0-FF}:{0-FF}:{0-FF}:{0-FF}:{0-FF}'
# 04:7C:DB:DB:11:0F
# 79:E7:1D:A7:42:43
# D6:C4:EC:8E:DF:32

# 随机生成 3 个 16 进制颜色
fake 3 @hexs -upper '2R0:#{0-FF}{0-FF}{0-FF}'
# #5F9197
# #5A6E58
# #04FF24
```
