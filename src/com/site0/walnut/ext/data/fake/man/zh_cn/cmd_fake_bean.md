# 过滤器简介

`@bean` 生成一个或者多个模拟的对象。

```js
{
  // 生成 UU32
  "key1" : "{FAKER}",
  // 嵌套对象
  "key2" : {...},
  // 模拟枚举
  "key3" : [...]
}
```

其中 `{FAKER}` 是一个字符串，可能的值为：

- `UU32`：生成 UUID 32 字符串
- `INT`：生成 0-100 的整数
- `INT:50-100`：生成 50-100 的整数
- `INTS:192.168.{100-200}.{0-255}`：生成随机的多段整数
- `HEX`：生成 0-FF 的整数
- `HEX:6F-FF`：生成 6F-FF 的整数
- `HEXS:2R0:#{0-FF}{0-FF}{0-FF}`：生成一个随机颜色
  - `8R0` 是零值填充的 `PADDING`，相当于为每段统一设置（可选）
- `STR`：生成随机的字符串
- `STR:5-10`：生成随机字符串，长度 5 至 10 个字符不等
- `SENTENCE`：生成一个随机句子
- `SENTENCE:5-10`：生成随机句子，内容为 5 至 10 个词不等
- `TEXT`：生成一段随机文本
- `TEXT:20-50`：生成随机文本，长度为 20 至 50 个字符不等
- `NAME`：生成一个随机人名
- `NAME:FAMILY`：生成一个随机姓
- `NAME:NAME`：生成一个随机名
- `NAME:MIDDLE`：生成一个随机中间名
- `AMS`：生成一个今天的随机毫秒数，语法见下文
- `AMS=today:5m`：生成今天 00:00:00 开始 5 分钟内的毫秒数
- `AMS=today:1h:yyyy-MM-dd HH:mm`：生成今天 00:00:00 开始 1 小时内的时间字符串
- `?A,B,C`：`?` 开头是半角逗号分隔的枚举型随机内容
- 其他情况，统统当作固定字符串
- `:{FAKER}XXX`：`:` 开头表示字符串模板，`{..}` 内还可以是一个 `FAKER`
- `PAD[8R0]:{FAKER}`：对结果进行 padding，其中 `8R0` 表示：
  - 宽度 `8`
  - 内容居右：支持 `[LR]`
  - `0` 可选，表示用 `0` 填充空位，不声明则用空格填充
- `UPPER:{FAKER}`：全部转换为大写
- `LOWER:{FAKER}`：全部转换为小写
- `CAMEL:{FAKER}`：转换为驼峰
- `SNAKE:{FAKER}`：转换为下划线分隔
- `KEBAB:{FAKER}`：转换为中划线分隔
- `SUBSTR30:{FAKER}`：对结果剪裁，不超过指定长度

## `AMS` 的语法

```bash
[AMS][=+][{Start}][:{Duration}][:{Format}]
```

- `[+=]`：生成随机数的方式
  - `+`：从 `{Start}` 开始以 `{Duration}` 为段，段内生成随机时间；同一个实例每次调用累加段下标，适合模拟按时间索引的数据（如日志）
  - `=`：从 `{Start}` 开始以 `{Duration}` 为长度的区间内随机取一个时间
- `{Start}`：开始时间
  - `today` 表示今天
  - `today+1d` 表示明天
  - `2020-12-09` 表示一个绝对的日期字符串
- `{Duration}`：时间长度
  - `1d` 一天 | `1m` 一分钟 | `1s` 一秒钟 | `500` 500 毫秒
- `{Format}`：日期时间格式化字符串，不指定则输出毫秒数

# 用法

```bash
fake [个数] @bean [设置JSON] [-lang 语言] [-to 目录] [-v]
  # 个数        # 生成多少个，默认 1
  # 设置JSON    # 模拟对象的设置；不给则试图从标准输入读取
  -lang        # 语言种类，默认 zh_cn
  -to          # 一个目标目录，将模拟的对象输出到对应目录
  -v           # -to 模式下，逐行打印输出对象的调试信息
```

# 示例

# 根据配置生成两个随机对象
cat bean.json | fake 2 @bean -lang en_us
