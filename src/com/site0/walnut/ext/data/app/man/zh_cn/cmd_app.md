# 命令简介

`app` 命令是一系列子命令的集合，协助界面（尤其是 obrowser UI）获取一个应用的必要信息：

- 应用的 i18n 字符串
- 域目录结构初始化
- 对象的编辑器和菜单配置

所有的命令动态读取 UI 配置，寻找路径参见环境变量 `$UI_PATH`，如果没有给定这个环境变量，则默认寻找 `/etc/ui`。

# 用法

```bash
app <子命令> [参数...]
```

支持的子命令：

```bash
@i18n    # 获取用户自定义的本地化字符串集合
@init    # 根据一个特殊的配置脚本，初始化一个域的目录结构
@setup   # 得到某对象的编辑器和菜单配置
```

# 示例

```bash
# 获取当前对象的菜单配置
app setup

# 获取 zh-cn 的本地化字符串
app i18n

# 初始化当前域的目录结构
app init
```
