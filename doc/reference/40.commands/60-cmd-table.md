# 命令总表

系统全部 157 个命令的清单。每个命令标注三个维度：

- **来源**：内置（`impl/box/cmd/`）或扩展（`ext/` 包）
- **写法**：简单 / 复杂 / 过滤，按主命令的继承关系划分，三者的区别见 01-cmd-simple、02-cmd-complex、03-cmd-filter
- **分类**：扩展命令按 `ext/` 下的包目录划分，是命令的逻辑分类

每个命令的手册与源码同包（`man/zh_cn/cmd_<命令名>.md`），运行时 `man <命令名>` 直接查看。
