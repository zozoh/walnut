# WnCron 定期表达式

WnCron 是 Walnut 的定期表达式，**完全兼容 Quartz Cron 六段语法**并做了扩展，核心库在 `src/com/site0/walnut/cron/`。它的设计目标之一：

> 「从今年下个月15号开始，每天的 8:00、10:30、14:40 各运行一次」——这种 Quartz 很难直接表达的场景。

## 库的定位

本库只负责**解析 → 解释 → 填充时间点**，不直接执行任务：

- **解析**：字符串 → `WnCron` 对象；
- **解释**：`toText(i18n模板集)` → 人类可读的中文描述；
- **填充**：`WnCron(expr).fill(数组, 对象, 日期)` — 给定长度为 N 的时间点数组，把对象填进被表达式命中的格子里。数组长度决定一天的切分粒度：24 格 = 每小时一个点，1440 格 = 每分钟一个点，最大 86400（每秒一个点）。

JS 与 Java 都能用：

```js
// JS 里
var arr = [];
WnCron('0 0 0/3 * * ?').fill(arr, "RUN", new Date());
// arr 里将出现：0点/3点/6点/.../21点 共 8 个 "RUN"
```

## Quartz 基础（六段）

```text
秒  分  时  日  月  周
0   0   0   *   *   ?
```

符号：`-` 范围、`,` 列表、`*` 全部、`/` 步进、`?` 仅用于日和周、`L` 最后、`W` 最近工作日、`#` 第几个星期几。例：

```text
0 0 0 * * ?          每天 0 点
0 0/5 8,10-14 * * ?  每天 8 点、10-14 点每 5 分钟
0 0 0 * * FRI#2      每月第 2 个周五
0 0 0 1LW * ?        每月最后一日最近的工作日
```

## WnCron 扩展

扩展部分可以出现在 Quartz 表达式的**前面或后面**：

```text
(扩展) (Quartz 时间部分) (Quartz 日期部分) (扩展)
```

### D[...]：限定日期区间

```text
D[20261001,20261008)   # 10月1日至10月7日（左闭右开）
```

### T[...]：限定时间区间

```text
T[08:12,09:16]              # 只在 8:12 至 9:16 之间的时间点有效
T[08:12,09:16]{0/30m}       # 区间内每 30 分钟一个点
T[08:12,09:16]{10s/30m}     # 偏移 10 秒开始，每 30 分钟
T[08:12,09:16]{>/30m}       # ">" 全天均分偏移：以 30 分钟为单位均分全天，取最近点
T{02:30,06:48,18:25}        # 明确指定自由时间点列表
```

要点：

- `T{...}` 或 `{offset/step}` 声明后，**Quartz 时间部分被无视**（写了也没用）；
- 步进单位：`s` 秒、`m` 分、`h` 小时；
- 区间语法是中学数学区间：`[` 闭、`(` 开；`[34,]` 表 ≥34，`(100)` 表 ≠100，`[100]` 表 ==100。

### 综合示例

```text
D[20261001,20261008) T{08:00,10:30,14:40}    # 国庆 7 天，每天三个时间点
D[,20261231] T[09:00,18:00){>/20m}           # 年底前每天工作时间均分（每 20 分钟）
```

## 解释成人类可读文本

`WnCron.toText()` 配合 i18n 消息模板集（JSON，见 `src/com/site0/walnut/cron/i18n/`）输出描述：

```bash
cron explain '0 0 8-11,13-18 * * ?'
# 每月的每天的8点至11点,13点至18点0分0秒
```

## 场景速查

| 需求 | 表达式 |
|---|---|
| 每 5 分钟 | `0 0/5 * * * ?` |
| 工作日 9 点 | `0 0 9 * * MON-FRI` |
| 每天工作时间每半小时 | `T[09:00,18:00]{0/30m}` |
| 活动期内每天 3 个时间点 | `D[20261001,20261031] T{08:00,10:30,14:40}` |
| 避免整点风暴（全员错开） | `T{>/15m}`（全天均分偏移） |

## 注意事项

- 扩展部分**不能包含空格**（`D[20261001,20261008)` 是一个整体）；
- 表达式精确到秒，但系统调度粒度是分钟（见 [调度流水线](cron-pipeline.md)）；
- `cron explain '<表达式>'` 是验证表达式是否如你预期的最佳工具。
