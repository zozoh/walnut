# Walnut 项目总体认识

> 通读 README、doc/_old/markdown（53 篇）、doc/_old/draft（212 篇）、src（约 3,200 个 Java 文件）、test（约 650 个文件）后的总结。时间：2026-10-21。

## 一句话定位

Walnut 是一个**业务系统开发基座平台**：用统一的虚拟文件系统（WnIo）整合 MongoDB / SQL / Redis / 本地文件 / 内存 / 消息队列等存储，用「一切皆对象 + 一切皆命令 + JS 动态脚本」的方式，让二次开发者通过配置和脚本而非编译代码来构建业务系统。

版本 16.07，Maven 工程，Jetty 9.4 内嵌，Nutz MVC + Nutz Ioc（Nutz 源码内嵌于 src/org/nutz）。

## 五条核心设计思想（源自 README，源码验证属实）

1. **统一存储抽象**：树形对象空间，任何目录可声明 `mnt` 映射到不同索引器（mongo/dao/mem/file/redis/mq）和桶管理器（LocalBM/LocalFileBM/RedisBM/AliyunOssBM）。
2. **命令化**：一切操作是命令，命令可拼装（管道 `|`、重定向 `>`）。内置命令 76 个（`impl/box/cmd/cmd_*.java`），扩展命令 85 个（`ext/**/cmd_*.java`），共 161 个。
3. **JS 脚本引擎**：`jsc` 命令 + JsExec 包裹层，业务逻辑可作为脚本存放在域目录中动态升级。
4. **开箱即用的内置功能**：支付、定时任务、HTTP API 注册、站点、数据集（Thing）、验证码、通知等。
5. **Java 库二次开发**：核心服务以 Ioc Bean 形式暴露，可作为库嵌入。

## 两个世界的账户

- **系统账户**（`/sys/usr`）：操作 Walnut 本身的账户，主组即域，`/home/$grp/` 为主目录。
- **域站点账户**（`~/accounts` ThingSet）：某个域自己运营站点的私有账户库。
- 桥梁：域账户可凭站点票据创建系统会话（`auth_login_by_domain_*`），登录后进入域主目录。

## 典型使用形态

1. 每个使用者/团队得到一个域（`~/`，即 `/home/$domain`）。
2. 在域内用 `~/.regapi/` 注册 HTTP 接口（一个文件 = 一个 API，内容是命令模板）。
3. 用 `~/.dao/`、`.io/`、`.weixin/`、`.aliyun/` 等约定目录接入外部资源。
4. 用命令 + JS 脚本完成业务逻辑；数据应用走通用对象/SQL 映射/通用实体（entity）路线。
5. 系统级能力（root 所有）：`/sys/cron`、`/sys/schedule`、`/sys/tasks`、`/var/session`、`/var/payment`、`/var/vcode`。

> **已弃用方向（2026-10 作者确认）**：www 站点模型（`cmd_www` 已删除）与 Thing 数据集概念均在弃用过程中。
> `cmd_thing` 目前仍在代码中（含 17 篇 man 手册），但新开发不应再基于它；相关文档不再投入。

## 生态系统线索

- 前端应用 `wn.manager` / `wn.console` / `ti`（titanium）通过 APP_PATH 环境变量加载，资源不在本仓库（WebContent/rs 下可能仅有引用）。
- hmaker / zui / obrowser 等 UI 文档（draft/ui 47 篇）描述的前端框架属于另一套体系，本草稿多为设计稿，与当前代码对应关系弱。
- draft 中 mediax 目标平台列表（头条/知乎/公众号等）大部分未在 ext/media/mediax 中实现（mediax 仅 22 个文件）。
