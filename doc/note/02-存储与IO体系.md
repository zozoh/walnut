# 存储与 IO 体系

## 核心模型：树 + 两段式 ID + 映射

WnObj 按树组织，根由 MongoDB 承载。任何目录可声明 `mnt` 映射：

```bash
mnt : "$IndexType[($Setting)][://$Storage]"
dao(abc/t_news)://aliyunoss(news-data)
```

- **索引器**（元数据存哪）：`mongo`(默认) / `dao`(SQL表) / `mem` / `file` / `redis` / `mq`
- **桶管理器**（内容存哪）：`LocalBM`(SHA1 去重，本地盘) / `LocalFileBM`(自然目录) / `RedisBM` / `AliyunOssBM`
- 映射节点 ID 为两段式 `$HomeID:$ReferID`，快速定位映射根。

## 实现类地图（core/）

```bash
core/io/           WnIoImpl2(主实现)、WnIoHookedWrapper(钩子)、WnIoCachedWrapper(缓存)
core/mapping/      WnIoMappingFactoryImpl：分析 mnt，产出 WnIoMapping(indexer+BM 对)
core/indexer/      mongo/ sql/ localfile/ vofs/ 四种索引器
core/bm/           bml(LocalSha1BM 本地桶+SHA1去重)、bmv、bml/localfile/redis/sql/vofs
core/hdl/          句柄管理：memory/ redis/ 两种
core/eot/          Expired Object Table：mongo 实现 + 清理线程
core/refer/        桶引用计数：redis/ mongo 两种
core/cache/        Io 对象缓存
core/stream/       读写流封装
core/bean/         WnIoObj(对象默认实现)
```

**读路径**：`WnIo.get(id/path)` → 命中缓存？(WnIoCachedWrapper) → 全局索引器取元数据 → 若 `mnt` 存在则用映射工厂取子映射 → 读桶。
**写路径**：`open(obj, W|A)` → 句柄管理器分配写句柄(默认1分钟有效) → 写入交换区(swap) → `flush/close` → 桶封盖算 SHA1 → 去重(LocalSha1BM 按 SHA1 命名桶文件) → 更新对象元数据(sha1/len/lm/data)。

## 去重与引用计数

- 本地桶按内容 SHA1 命名（`buck/0evq/89..g1`），重复内容自动去重。
- `WnReferApi`（Redis 实现默认）维护 `io:ref:$SHA1 = ID1,ID2...`，桶被引用计数。
- 文档 c0-io-tree-and-bucket.md 与 draft/core/storage.md 描述的「桶链封盖」设计部分已实现于 LocalSha1BM，细节以代码为准。

## 过期对象（expi）

- 对象元数据 `expi`（绝对毫秒）→ EOT 表记录 `{id, expi, hold, ow}`。
- 单节点单清理线程，启动时抢锁（WnLockApi），批量取过期对象处理，`hold` 字段防多节点竞争。

## 查询体系

- `WnQuery`：pid + 条件(regex/区间/精确/limit/skip/sort/lbls)。
- `WnObjMatcher`：内存匹配器（钩子条件、hook_by 匹配用）。
- 聚合 `agg/`：`WnAggOptions` 定义 group keys + 聚合函数（count/sum/...），`WnAggregateKey` 支持多级分组和日期截断。

## 环境配置形态

域用户可自定义（约定目录）：

```bash
~/.dao/*.dao.json        SQL 数据源
~/.io/ix/*.json          DaoIndexer 映射定义(表结构/字段映射/索引)
~/.io/bm/*.json          RedisBM 定义
~/buck/、~/swap/         LocalBM 落地目录（域级桶）
```

系统级（root）配置在 `/etc`（hostmap、thumbnail、sysconf、ui 等）。
