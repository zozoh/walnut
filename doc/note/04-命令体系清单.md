## 命令组合范式（Walnut 的"编程方式"）

```bash
# 管道与重定向
obj id:xxx -cqn | json -u 'phone:"${phone}"' > id:xxx        # 改元数据
cat ~/data.txt | grep ERROR | wc -l                          # 文本处理
obj * -match -t 'id,nm,expi' -bish | run                       # 批量执行

# 模板渲染 + 命令注入
obj /domain -tmpl 'obj id:@{id} -u \'tp:"A"\';' | run

# JS 脚本
jsc ~/bin/mylogic.js -vars 'id:"${id}"'

# MQ 异步
mq send -user demo 'echo hello > ~/abc.txt'
```
