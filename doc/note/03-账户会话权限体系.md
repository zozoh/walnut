# 账户、会话、权限体系

## 账户双轨

### 系统账户（/sys/usr）
- 每个用户一个文件，`id/nm/phone/email`(均唯一) + `passwd/salt` + `grp`(主组) + `home/open/theme`。
- 角色表 `/sys/role/ID{uid,grp,role}`，组 `/sys/grp/$grp/people/`（旧结构，查询时自动迁移）。
- 组角色值：`-1` 黑名单 / `0` 非组员 / `1` 管理员 / `10` 组员 / `100` 预备。
- 初始化脚本约定：`/sys/setup/usr/create/{通用,init类型}`、`/sys/setup/usr/login/...`（登录初始化）。

### 域站点账户（~/accounts, ~/roles）
- ThingSet 存放，`~/www` 站点目录通过 `accounts` 元数据关联账户库。
- 业务角色：字符串名（admin/member/...），`isdft` 默认角色，`mainpage` 着陆页。
- 特殊角色 `others`：登录后固定加载，可用 `@others` 指定对象默认权限。
- 组织结构：站点 `organization.json` 树（G 组/P 职位），用户 `job/dept` 字段，对象 `belong/pvg{+节点}`。

## 会话

- 对象化：`/var/session/${TICKET}`，元数据 `{id,nm,expi,uid,unm,by_tp,by_val}`，内容 JSON 存环境变量。
- 多级登录：`su - user` 建立子会话（`p_se_id` 链），`exit` 回父会话；touch 子会话同时 touch 父链。
- 登录方式（by_tp）：web_passwd / web_vcode / wx_gh_* / microapp / session（子会话）。
- 域站点会话：`~/.domain/session/${SITE}/${TICKET}`，凭 ticket 可换系统会话（混合登录）。
- 自动登录：ackey 签名（sha1(ackey,user,time,once)），见 draft/core/auto_login.md。
- Token 机制（draft/core/token.md）：appid+nonce+timestamp+sign(sha256)，防重放。

## 权限三层

1. **mode 三段八进制**：admin/member/others 的 rwx。第一段是 admin 而非 owner——设计强调组内协作多人共管。
2. **扩展 pvg 元数据**：对象可声明 `pvg:{user|@role: 八进制}`，向上查祖先，父优先。
3. **业务权限模型（c2-pvg）**：角色×动作的 JSON 表，`pvg` 命令 / `WnPvgMoreService` 被动查询，应用于 HTTPAPI/界面/脚本。

## 执行身份切换

- `Wn.WC().su(user)`：线程级身份切换，WnBoxService 沙箱执行。
- MQ 消息 `{type:CMD,user,secret,body}`：执行器切身份执行 `~/.mq/secret` 校验密钥。
- `login <user>` 命令：`op` 组管或 `root` 组成员可切换（输出新会话，10 秒有效期，客户端走 `/u/ajax/chse` 换 cookie）。

## 与其他模块的关系

- `login/` 提供 WnUserStore/WnRoleStore/WnSessionStore 三套接口，Std(本地)/Sql 双实现 + Proxy。
- HTTPAPI 层：`http-www-home/ticket/auth` 元数据驱动站点会话注入；`pvg-setup/pvg-assert` 元数据驱动业务权限校验。
- 历史记录：操作历史落 `/grp/$grp/history`（uhis 类型）或通用实体的 history 表（SQL）。
