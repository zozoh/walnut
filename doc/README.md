# Walnut 文档

Walnut 是一个**业务系统开发基座平台**：用统一的虚拟文件系统（WnIo）整合 MongoDB / SQL / Redis / 本地文件 / 内存 / 消息队列等存储，用「一切皆对象 + 一切皆命令 + JS 动态脚本」的方式，让二次开发者通过配置和脚本而非编译代码来构建业务系统。

本站点由 `www-gen-site` 从 `doc/` 目录自动生成，分为两个栏目：

- **note** —— 项目阅读笔记：通读源码与旧文档后的体系化总结，适合按顺序了解项目全貌；
- **reference** —— 参考手册：以 AI Agent 为主要读者的结构化参考文档，按主题模块组织，可凭关键词快速定位。
